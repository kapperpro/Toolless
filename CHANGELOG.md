# Changelog

## v0.9.2

- **Startup page** in the Task Manager: enable, disable and sort startup entries.
- **Performance view** redesigned like the Windows Task Manager, with an Advanced mode (CPU cores, cache sizes and more hardware details). Disks and GPU now fit without scrolling in normal mode.
- **Task Manager history:** choose how long history is kept (1–30 days), a larger and zoomable timeline with date/time marks, and filtering by custom date or time range.
- **Process list:** resizable columns and clearing the selection with Esc.
- **All tabs:** new Refresh button (F5) and more consistent card titles.
- **Clock:** larger clock, alarms, countdowns and stopwatches.
- **Repository:** cleanup script, `.gitignore` and GNU AGPL v3.0 license.
- Fixed layout and scrolling issues in the Performance view, a flat history graph and a build warning.

## Coming next

- Built-in seed map and save/chunk selector in the Minecraft tab.
- Linux and macOS releases.
- And more.
